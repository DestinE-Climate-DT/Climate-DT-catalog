# What is this catalog?

This is the consolidated catalog for climatedt-gen2 simulations (i.e. simulations from o25.1 and possibly o26.1)
It contains a structure to organize the result of the run for the models involved in the ClimateDT project.

Using this machine will point to the correct location for grids and observations necessary for the analysis of such models.

The LRA zarr files are available also in the Lumi-o bucket, and the path to this bucket is set as default in the catalog.yaml file.
Please consider this an experimental feature.
